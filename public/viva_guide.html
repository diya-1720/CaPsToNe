1. 🎯 60-Second Opening Elevator Pitch

"Good morning, respected examiners. Traditional fitness wearables fail because they compare users against generic medical averages — sounding alarms whenever heart rate crosses an arbitrary 100 BPM, regardless of individual fitness or whether the user is climbing stairs. AWEN introduces two core breakthroughs: Personal Baseline Calibration, where the system establishes your individual resting corridor (μ ± 2σ) over an observation period to ask 'Is your body behaving unusually for YOU?'; and Multi-Modal Exertion Filtering, which fuses optical PPG with 3-axis kinetic acceleration to distinguish exercise from acute psychological stress. Running on an edge ESP32 sensor pod, local FastAPI backend, and React 19 interface with a 60 FPS living vector mascot, AWEN delivers clinical privacy and emotional calm."

2. 🏗️ Tech Stack & Architectural Rationale

Dual Communication Wi-Fi REST (172.20.168.254) + Web Serial Wi-Fi enables local network streaming; Web Serial provides zero-latency driverless USB UART direct to the browser.
Backend Engine Python 3.12 FastAPI + Uvicorn Asynchronous non-blocking event loop, Pydantic validation, and OpenAPI documentation at /docs.
Machine Learning Scikit-Learn Isolation Forest Unsupervised multi-dimensional anomaly detection that isolates anomalies in O(n log n) time without requiring labeled clinical datasets.
Database Persistence Local SQLite with WAL Mode (awen.db) 100% data sovereignty. Zero cloud network latency, zero data leak risks, and concurrent non-blocking reads/writes.
Frontend & UI React 19 + Vite 6 + Tailwind CSS Sub-second Hot Module Replacement, optimized Rollup bundles, and 60 FPS GPU-accelerated SVG mascot animations.

3. 🧮 Mathematical Formulas & Algorithms

Personal Baseline Corridor (μ ± 2σ)

Given rolling resting observations {x₁, x₂, ..., xN}:

Mean (μ) = (1/N) * Σ x_i
Variance (σ²) = [1 / (N-1)] * Σ (x_i - μ)²
Personal Tolerance Corridor = [ μ - 2σ , μ + 2σ ]
Z-Score Deviation (Z_t) = (x_t - μ) / σ

By Chebyshev's inequality, at least 75% of values fall within 2σ for any distribution, and 95.45% for a normal resting Gaussian distribution.

Motion Vector Magnitude

|a| = √(ax² + ay² + az²)
Motion Flag = TRUE if ||a| - 1.0g| > 0.25g

Stress Decision Matrix

  • Elevated HR + Motion = TRUE: Physical exercise → Alarm suppressed, Mascot enters Active (Amber) aura.
  • Elevated HR + Motion = FALSE + Temp Drop: Genuine psychological distress → Soft alert triggered, Mascot enters Watchful state with 4-7-8 breathing prompt.

4. ❓ Top 20 Common Viva Questions & Flawless Model Answers

Q01: Why did your team not deploy the database to the cloud?
Answer: "For biometric data sovereignty and ethical AI compliance. Biometric telemetry (pulse waves, heart rates, daily reflections) is intimate personal data. Shipping it to cloud servers exposes the user to remote database breaches and commercial data brokers. By keeping SQLite in WAL mode on the local machine, the user retains 100% ownership of their health data with zero cloud latency."
Q02: How do you prevent false alarms when someone climbs stairs or exercises?
Answer: "Through multi-modal sensor fusion. We correlate photoplethysmography (MAX30102) with 3-axis accelerometer readings (MPU-6050). When the total kinetic acceleration magnitude |a| exceeds 1.25g, AWEN recognizes that tachycardia is physiologically expected for physical locomotion, suppresses the panic chime, and transitions the mascot to an encouraging 'Active' state."
Q03: What prevents the buzzer and anomaly popup from beeping continuously?
Answer: "We engineered a dual-layer refractory cooldown:
1. Firmware level: A 60-second hardware lockout timer in esp32_max30102.ino ensures the piezo buzzer cannot trigger again within 60,000 milliseconds.
2. Frontend level: A 180-second chime debounce timer in AbnormalReadingPopup.jsx ensures the user is not stressed by repetitive audible notifications."
Q04: What is the significance of the 5 mascot colors?
Answer: "The colors correspond to autonomic states:
• Balanced (#34d399 Emerald): Resting biometrics within personal baseline corridor.
• Learning (#a855f7 Lavender): Calibration mode during days 1-3.
• Active (#f59e0b Amber): Kinetic movement detected.
• Watchful (#f97316 Coral): Resting tachycardia without motion.
• Wind Down (#6366f1 Indigo): Evening rest mode with floating 'Zzz' particles."
Q05: Why did you use Isolation Forest instead of a neural network?
Answer: "Neural networks require massive labeled datasets of pathological stress versus normal readings, which do not exist for an individual consumer. Isolation Forest is an unsupervised algorithm that isolates anomalies in O(n log n) time by randomly sub-sampling features and measuring tree path length. Since anomalies are few and structurally different, they require fewer splits to isolate."
Q06: What I2C devices are connected and what are their addresses?
Answer: "All three sensors share the ESP32 fast-mode I2C bus on GPIO 21 (SDA) and GPIO 22 (SCL):
• 0x57: MAX30102 Pulse Oximeter
• 0x68: MPU-6050 6-Axis IMU
• 0x3C: SSD1306 0.96 inch OLED display"
Q07: How does Web Serial work without installing drivers?
Answer: "The W3C Web Serial API allows web applications to communicate directly with serial devices over USB CDC (Communications Device Class). The browser opens the UART port at 115,200 baud, reads UTF-8 JSON lines from the ESP32 serial buffer, and parses them directly into React state."
Q08: What is the purpose of the 7-Window personality engine?
Answer: "To make the companion feel alive and circadian-aware. The engine maps time into 7 natural windows (Early Morning, Morning, Lunch, Afternoon, Evening, Night, Late Night) and cascades priority from time → health vitals → activity → recent conversation memory, guaranteeing zero repetitive lines."
Q09: Does AWEN provide medical diagnoses?
Answer: "No. AWEN is strictly a supportive wellness companion. It frames observations in non-diagnostic language (e.g. 'Your resting heart rate is slightly elevated compared to your typical quiet baseline') rather than clinical terms ('You have tachycardia') to prevent medical hypochondria."
Q10: What is the emergency contingency if Wi-Fi drops during the viva demo?
Answer: "We plug the ESP32 USB cable into the laptop, click 'Connect Web Serial', and the web application instantly switches to live hardware streaming over direct USB UART at 115,200 baud."
